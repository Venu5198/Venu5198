### 🚀 About Me

I work primarily with AWS, Google Cloud, Kubernetes, and CI/CD systems, supporting 20+ microservices in production. My focus is simple: reliability, automation, and cost efficiency.  
💻 What I Do  
Design and operate Kubernetes-based platforms handling millions of requests per day  
Build and optimize CI/CD pipelines using GitHub Actions and Jenkins  
Implement GitOps workflows with Argo CD  
Drive autoscaling, resource optimization, and cost control  
Achieved 99.9%+ availability  
Reduced cloud spend by 20–25%  
Optimize Docker images for faster builds and deployments  
Deliver zero-downtime releases using rolling and blue-green deployments  
📊 Reliability &amp; Observability  
Set up monitoring and alerting with Prometheus, Grafana, and Splunk  
Improved incident detection and recovery times by 30–35%  
Made on-call more predictable and less reactive  
🔐 Security &amp; Governance

Manage secrets safely  
Enforce RBAC and least-privilege access  
Keep environments audit-ready
